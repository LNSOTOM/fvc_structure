# Preparing 3D U-Net Tensors From Labelled Point CSVs

This note describes how to turn the labelled point catalogue produced by
`voxel_point.py` (`xyz_norm_with_labels.csv`) into voxel tensors that can be fed to a
3D U-Net. The workflow keeps the voxel grid aligned to the fractional vegetation
cover (FVC) mask so the volumes are spatially consistent with the existing raster
labels.

## 1. Required Inputs

- `xyz_norm_with_labels.csv` generated by `voxel_point.py` (columns: `X`, `Y`,
  `Z_norm`, `Label`).
- `voxel_points_meta.json` generated alongside the CSV (stores the LAS source,
  label set, kept fraction, and the vertical extent).
- The FVC raster mask that was sampled when creating the CSV. Its affine
  transform defines the voxel cell size and XY origin.

Optional but useful:

- `voxel_meta.json` emitted by `voxel_visualization.py` when you already ran the
  voxel pipeline; it contains the same grid/voxel size metadata and can be reused.

## 2. Coordinate System and Voxel Layout

- XY indices come directly from the mask grid. Each pixel (5 cm) becomes one
  voxel cell in the XY plane.
- The Z axis is discretised in the same 5 cm steps (or whatever pixel size the
  mask uses). The origin (`z_min`) is the minimum normalised height reported in
  the CSV/meta file.
- We build a tensor in either `(Z, Y, X)` or `(Y, X, Z)` order depending on the
  DL framework. The example below stores `(Z, Y, X)` which maps naturally to
  PyTorch tensors (`C × D × H × W`).

## 3. Example Conversion Script

The snippet below illustrates how to rasterise the CSV into three stacked
volumes: occupancy (binary), point count, and dominant label. Adjust file paths
as needed.

```python
from pathlib import Path
import json
import numpy as np
import pandas as pd
import rasterio

# --- configuration ---------------------------------------------------------
workdir = Path("phase_2_labeling_workflow/output_tile_26")
csv_path = workdir / "phase_2_labeling_workflow/xyz_norm_with_labels.csv"
meta_path = workdir / "phase_2_labeling_workflow/voxel_points_meta.json"
mask_path = Path("/media/laura/.../mask_fvc_3072.26.tif")
voxel_size_override = None  # set (e.g. 0.1) to use a coarser vertical step

# --- load inputs -----------------------------------------------------------
df = pd.read_csv(csv_path)
meta = json.loads(meta_path.read_text())
with rasterio.open(mask_path) as src:
    transform = src.transform
    width, height = src.width, src.height
    pixel_size = abs(transform.a)
    crs = src.crs
    assert np.isclose(pixel_size, abs(transform.e)), "Mask pixels must be square"

vs_xy = pixel_size
vs_z = voxel_size_override or pixel_size
z_min = meta["z_range"]["min"]
z_max = meta["z_range"]["max"]

# --- index computation -----------------------------------------------------
cols, rows = rasterio.transform.rowcol(
    transform,
    df["X"].to_numpy(),
    df["Y"].to_numpy(),
    op=float,
)
cols = cols.astype(np.int64)
rows = rows.astype(np.int64)

iz = np.floor((df["Z_norm"].to_numpy() - z_min) / vs_z).astype(np.int64)
iz = np.clip(iz, 0, None)
nz = int(iz.max()) + 1

nx, ny = width, height
shape = (nz, ny, nx)

# --- allocate volumes ------------------------------------------------------
occupancy = np.zeros(shape, dtype=np.uint8)
point_counts = np.zeros(shape, dtype=np.uint32)
dominant = np.full(shape, -1, dtype=np.int32)

# flatten indices for aggregation
flat = iz * (ny * nx) + rows * nx + cols
uniq, inv = np.unique(flat, return_inverse=True)

np.add.at(point_counts.ravel(), flat, 1)
occupancy.ravel()[flat] = 1

labels = df["Label"].to_numpy(dtype=np.int32)
uniq_labels = np.unique(labels)
label_idx = np.searchsorted(uniq_labels, labels)

votes = np.zeros((uniq.size, uniq_labels.size), dtype=np.uint32)
np.add.at(votes, (inv, label_idx), 1)
majority = uniq_labels[votes.argmax(axis=1)]
dominant.ravel()[uniq] = majority
dominant[occupancy == 0] = -1

# --- save tensors ---------------------------------------------------------
np.savez_compressed(
    workdir / "unet_voxel_tensors.npz",
    occupancy=occupancy,
    point_counts=point_counts,
    dominant_labels=dominant,
    voxel_size_m=dict(x=vs_xy, y=vs_xy, z=vs_z),
    origin=dict(x=transform.c, y=transform.f, z=z_min),
)
```

### Notes

- `rowcol` handles the affine transform, so no manual floor/offset is required.
- The tensor uses `(Z, Y, X)` ordering. Swap axes if your framework expects
  `(Y, X, Z)` or `(C, D, H, W)`.
- Keep the metadata (voxel size, origin) alongside the `.npz` so you can warp the
  predictions back to world coordinates.

## 4. Exporting Raster Stacks for QA

To inspect individual Z slices in GIS software, write the dominant-label volume
as a Cloud-Optimised GeoTIFF stack:

```python
import rasterio

stack = dominant  # (Z, Y, X)

profile = {
    "driver": "COG",
    "dtype": "int16",
    "width": nx,
    "height": ny,
    "count": nz,
    "transform": transform,
    "crs": crs,
}

with rasterio.open(workdir / "dominant_labels_stack.tif", "w", **profile) as dst:
    for band in range(nz):
        dst.write(stack[band, :, :], band + 1)
```

This produces a multi-band raster where each band represents a 5 cm vertical
slice. Occupancy and point-count stacks can be exported the same way (choose
appropriate dtypes).

## 5. Feeding a 3D U-Net

- Normalise point counts (e.g. log transform) and optionally stack auxiliary
  layers (DSM, canopy height, etc.) to form a multi-channel tensor.
- Serialize the training volume as `.npz`, `zarr`, or PyTorch `.pt` files. When
  slicing into patches, keep track of voxel origin to warp predictions back.
- Store the label mapping (e.g. `0 → photosynthetic`, `1 → litter`, etc.) in the
  dataset config used by the network so class identifiers remain consistent.

With the CSV, metadata, and mask transform, you can now derive all required
raster-aligned tensors for downstream 3D segmentation.
